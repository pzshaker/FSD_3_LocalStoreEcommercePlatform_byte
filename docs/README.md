This folder records the agreed product decisions and the current technical direction for the artisan bakery ordering app.

## Decision status

Product decisions in the requirements document were chosen during planning. The stack and backend-first approach were also selected. API route names and request/response shapes track the implemented service.

The visual direction is selected: Stitch Direction 2, Contemporary Neighborhood Market. The bakery brand, address, currency, verified product catalog, and other open policy details remain undecided; see [screens](screens.md).
